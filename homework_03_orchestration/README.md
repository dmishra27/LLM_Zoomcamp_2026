# Overview

This directory contains my work, notes, flow definitions, screenshots and execution logs for **Module 3 – AI Orchestration with Kestra**.

Unlike the previous modules, this module focuses on orchestrating AI workflows rather than building standalone AI components. Using **Kestra**, we learn how to coordinate LLMs, Retrieval-Augmented Generation (RAG), AI agents, external tools and workflow execution into reliable production pipelines.
